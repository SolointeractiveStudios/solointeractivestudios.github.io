Studio API Reference

Basic API usage guide and interactive sections for backend links, general calls, and rich presence.

Basic API Usage

Use these endpoints to connect your backend to the Studio API. Replace the placeholders with your own values and call from your server environment.

const response = await fetch('https://api.studio.example.com/v1/test', { method: 'GET', headers: { 'Authorization': 'Bearer YOUR_API_KEY', 'Content-Type': 'application/json' } }); const data = await response.json(); console.log(data);

Backend link examples:

  • GET /v1/account/status
  • POST /v1/session/create
  • PUT /v1/profile/update

Rich Presence

Add rich presence information for your application to show live status, active project, or custom details.

const presence = { status: 'Editing project', details: 'Working on Studio API integration', project: 'TheInsecureCalculator', startedAt: new Date().toISOString() }; const response = await fetch('https://api.studio.example.com/v1/presence/update', { method: 'POST', headers: { 'Authorization': 'Bearer YOUR_API_KEY', 'Content-Type': 'application/json' }, body: JSON.stringify(presence) });

Rich presence data supports custom state, timestamps, and project metadata.
